# 拆解评分表（八问怎么答才算答了）

这套清单是从"这支片到底有几分是真的"这个问题倒推出来的。每一问都要落到**可指认的证据**上，
否则就是复述剧情。

## 1. 它声称什么
抄原话，一条一行，标出处（字幕 / 口播 / PPT / 图标）。不要转述、不要润色。
例：`「放弃全部作品，72 小时从零开始」——00:00 字幕`。

## 2. 画面证明了什么
逐段判类型，只有三种：

| 类型 | 判据 |
|---|---|
| **实机** | 有系统状态栏/光标抖动/输入法/加载态；文字与真实字体一致；同一 UI 在不同镜头里连续性一致 |
| **设计稿/CG** | 固定 9:41、按钮无 hover 态、文字完美对齐、镜头运动不符合人手、绒布/毛发质感是 AI 视频特征 |
| **纯叙事** | 大字报、章节号、无 UI |

一节判完再判下一节，别整片笼统说"是演的"。

## 3. 数字从哪来
每个数字都要问：分母是什么？时间窗是什么？谁统计的？
`「懂你 87%」`——没有分母 → 叙事。
`「NEXT 2H 客流预测 ↑136%」`——没有基线 → 叙事。
`「301 万」`这种若来自公开年报 → 有源。

## 4. 流程完整吗
真实 agent 产品的界面一半是过程：加载、重试、失败、确认、超时、权限卡、成本。
片子里全没有 → 说明它演的是"结果"，不是"流程"。
**反例（真东西长什么样）**：一张带"先不了 / 关注"两键的审批卡。

## 5. 约束与合规
品牌授权、真实数据接入、审批与审计、隐私（尤其"匿名转达"这类中介角色）、未成年人。
不是挑刺，是判断"能不能真的交给商场用"。

## 6. 作者自己怎么说
评论区常出现比片子更硬的信息：`「实机演示明天再发」`、`「0 个 skill」`、`「都是 agent，但这个不是 personal agent」`。
作者的一句话能推翻整段结论，先看评论再看片。

## 7. 它缺什么 / 我补得上什么
写成两列：它没有的（过程、数据、审计、IP）／我有的（跑起来的系统、真实动作、证据链）。

## 8. 可复用的方法论
只保留能迁移的结构：命题→原语的映射、三端共享一个脑、章节化叙事。
片子本身不可复用，结构可以。

## 输出纪律
- 结论先行：一句判断 + 三条证据，再展开。
- 每个判断后面挂时间码，方便别人自己去看那一帧。
- 不确定的标"推测"，别把推断写成事实。
